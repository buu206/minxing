## 本版包含什么

- 用户确认的绒毛菌群首页：细密菌丝、青绿与紫色层次、萤萤入口。
- 约三秒的同景近景拉开进场，可跳过、重播。
- 菌群纹理的局部呼吸与真实取样放大镜；这是装饰性视觉效果，不改变培养记录。
- 下滑时，首页景观收拢并衔接到可操作的培养皿；图鉴、画室延续同源纹理。
- 既有培养、监控、发现记录、图鉴、画室及本地存档等原型流程。
- 可操作的 AI 功能演示：按规则读取当前模拟数据、组织回复和提供操作入口，尚未连接大模型。

## 当前边界

- 产品运行端没有接入 LLM Agent、RAG、真实模型 API 或云端账户系统。开发时使用的 AI 协作工具与产品能力分开说明。
- 培养数据为教学原型的模拟结果，不应作为真实培养实验的定量预测。
- 存档主要保存在当前浏览器的 `localStorage`，不是云端同步。更换浏览器、访问域名或端口可能看到不同存档；清除站点数据会影响存档。
- Three.js、主要脚本和景观图片已包含在交付文件中。页面仍尝试加载可选 Google Fonts；字体不可用时使用系统字体。不要把“核心原型可离线打开”描述成“完全没有任何外部请求”。
- 主 3D 展台需要浏览器支持 WebGL。首页呼吸纹理的局部降级，不等于整个产品已经完成低配 2D 自动兜底。

# 皿星 · 菌落动态首页

本版以作者 2026-11-08 最后贴出的绒毛菌落视觉稿为准：`approved-concept.png`。保留白色细密菌丝、青绿与紫色层次、左上标题和底部 AI 入口。

本版进场为「万千微光，汇成萤萤」：有景深的萤光星群沿彩色光流连接、聚合为萤萤，再落入首页；菌丝由同一落点逐级分叉，首页菌群显色展开。光点最终与首页 AI 标记对齐，既有菌群呼吸、鼠标放大镜和滚动观察衔接保留。

首次访问与手动重播约 10 秒，三段文案分别完整停留约 2.4、2.4、2.3 秒，切换不依赖动画阶段；回访短版为 1.1 秒。支持「进入首页」、Escape 跳过，减少动态偏好直接进入首页。星群使用缓存辉光精灵和空间投影，手机减少粒子数量；进场前段暂停背景菌群绘制，结束清空星群画布。播放记录使用独立的本地标记，不修改个人培养存档。动画中的“知识汇聚”和生长为视觉叙事，不表示实际模型训练或科学培养计算。

`../colony.html` 是可独立打开的交付页面；Three.js 和景观图片均已内置。仓库根目录的 `index.html` 跳转到当前版；历史 A 版仍保留在作者本机，不将它与当前入口混用。

## 修改与构建

- 首页结构和样式：`home.html`、`home.css`
- 生长前沿、放大镜、萤萤光点：`life-visual.js`
- 星群空间投影与光流：`entry-constellation.js`
- 进场与页面衔接：`intro.*`、`home.js`
- AI 对话：`assistant.*` 与 `live-ai.js`；线上调用 Cloudflare 后端，本地调用 Python 网关
- 首页底图：`colony-landscape.png`
- `original.html` 是组合所用的 A 版基础快照；培养室、图鉴、画室等现有功能由它保留。

安装构建工具后运行：

```sh
npm install
npm run build
```

构建使用固定的 Three.js 0.165.0 本地模块和 esbuild 0.25.12，输出上级目录的 `colony.html`。生成的 `assembled.html` 和 `module.mjs` 是中间文件。

首页景观为视觉演示；同源放大镜读取变形后画布中同一位置的纹理。首页装饰性呼吸与生长不会改变培养记录。真实培养过程仍由培养室生长引擎计算。减少动态偏好会关闭自动生长、呼吸和进场动画，离开首页、隐藏标签或完成景观到培养皿的交接后暂停首页绘制。离屏纹理通道不可用时保留静态底图与既有交互。
